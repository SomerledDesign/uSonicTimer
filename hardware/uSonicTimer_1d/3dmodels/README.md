# 3D models: uSonicTimer rev 1d

This folder holds the project-local 3D models. Footprints reference them as
`${KIPRJMOD}/3dmodels/<file>.step`. The other bodies on the board (resistors,
capacitors, LEDs, Q1-Q5, SW1, U1, U3 and so on) come from the stock KiCad 10 3D library
(`${KICAD10_3DMODEL_DIR}`, installed with KiCad). That library is licensed under CC-BY-SA 4.0
with the KiCad library exception, so it can be used in any design.

## Our own models (in this folder)

Drawn by Somerled Design (Kevin Murphy) with Mildrew (Grok Bot).
Licence: CERN-OHL-S-2.0 (same as the rest of this hardware; see `LICENSE-HARDWARE` in the repository root).

Each model comes as a multi-colour STEP (one coloured solid per part) and a coloured VRML
(`.wrl`, KiCad scale 1 unit = 2.54 mm). Both are generated by `build_3dmodels.py` in this folder (CadQuery; run `python build_3dmodels.py`), which is the editable source. The model origin is
the footprint origin, so every footprint uses offset 0 0 0, scale 1 and rotation 0 0 0.
Dimensions are taken from the datasheets listed. Where a datasheet gives no value, the table
says what was used instead.

### ENC1: Alps EC11E with push switch, vertical, 20 mm shaft

From the datasheet:
- Body 12 x 11.7 mm. Shaft axis 7.5 mm from pins A/C/B and 7 mm from switch pins D/E.
  A-C-B pitch 2.5 mm, D-E 5 mm.
- Mounting surface 4.5 mm above the PCB. Overall height 24.5 mm (20 mm from the mounting surface).
- Bushing length 7 mm.
- Shaft Ø6 mm, flat 4.5 mm across over the top 10 mm.
- Pins and mounting tabs 3.5 mm below the PCB.

Not given in the datasheet, so assumed:
- Bushing Ø7 mm.
- Split between the black housing (0-3.8 mm) and the silver metal frame (2.0-4.5 mm).
- Pin cross-section 0.3 x 0.8 mm and tab size 2.0 x 0.5 mm.
- Tip chamfer 0.5 mm (the drawing says C1).
- Direction of the shaft flat.

The mounting tabs are drawn at the footprint's MP pads, which are 11.2 mm apart. The datasheet
hole pattern gives 12.5 ±0.05 mm.

### J1: 5-way 5.0 mm terminal block (Metaltex BR4)

From the datasheet:
- 5.0 mm per way; body 25 mm long (2.5 mm overhang past the end pins).
- 10.2 mm deep. Pin 5 mm from the wire-entry face, which faces the footprint's +Y side, where
  the silkscreen entry marks are.
- 14.2 mm high. Pins 0.8 mm square, 3.5 mm long.
- M2.5 zinc-plated screws; green PA66 housing.
- Drawn as one 2-way plus one 3-way block (BR402V + BR403V), with the joint between pins 2 and 3.

Not dimensioned in the drawing, so read off it:
- Shoulder height 9 mm and top width about 6.2 mm.
- Wire-entry opening 3.2 x 5.8 mm.
- Screw head Ø4 mm, recessed 1.8 mm.

The 0.6 mm interlock step is not modelled.

The board previously used Metaltex `BR1102V` + `BR1103V` models scaled by 0.5. The BR11 series
(https://metaltex.com.br/cdn/shop/files/br11.pdf) has a **9.5 mm** pitch, so it does not fit this
5.00 mm footprint. BR4 is Metaltex's 5.0 mm modular equivalent. The footprint's own fab outline
is a generic 27 x 9.5 mm box, so the model is 1 mm deeper at the back than that outline.

### U2: bare Nokia 5110/3310 LCD in its metal frame

The footprint is for the bare LCD with its metal frame (elastomer contacts on 9 SMD pads, four
frame tabs in slots, backlight LEDs D1-D4 on this board), not for the red/blue breakout board.
So the model has no breakout PCB or header.

From the datasheet:
- Glass 38.36 x 33 mm, with a 6.4 mm contact ledge (upper plate 26.6 mm).
- Glass stack 2.0 mm thick (maximum).
- Viewing area 34.96 x 23.4 mm, 1.7 mm from the glass edges.

From Kevin's measurements:
- Frame opening 36.23 x 25.85 mm.
- Frame borders: 1.6 mm left and right, 6.77 mm on the contact side, 1.45 mm on the other side.
- So the frame outline is 39.43 x 34.07 mm. Its contact-side edge is on the footprint's y = 0
  silk line, as in the bezel notes.

Assumed or taken from the footprint:
- Frame top 4.4 mm above the PCB. This is the 6 mm module thickness (Hobby Components spec)
  minus the breakout PCB; no datasheet gives it.
- Light guide 2.1 mm, with LED pockets at the silkscreen notches.
- Locating pegs in the two Ø2 mm holes.
- Tabs 0.4 x 2.8 mm at the slot centres.
- Elastomer strip 10 x 3 mm.

### Where the excluded models came from

Kevin downloaded most of the excluded models from **3D ContentCentral**
(3dcontentcentral.com, run by Dassault Systèmes; the site appears to be gone now):
- Q1-Q5 `User Library-SOT23-3`
- ENC1 `User Library-EC11B15244`
- probably the SW1 and J1 models too

The `User Library-…` file names match 3D ContentCentral's export naming. These models
were uploaded by users under Dassault's terms, which give no licence to redistribute
them, so they are not included in this CERN-OHL-S repository. Keep them in a local
library instead. The EC11 encoder model (`EC11 Rotary Encoder Dode Switch-15mm`) is
attributed to GrabCAD user *xindela*, as above.

`${MYSPECLMOD}` is not defined in Kevin's KiCad 9/10 configuration. So none of the
`MYSPECLMOD` models resolved on any machine before this change either.

To see the original third-party bodies locally, Kevin can add them back in his own copy, but
must not commit them. Use `${KIPRJMOD}/3dmodels/<file>`, add the file names to a local
`.git/info/exclude`, and use the offsets listed above.
